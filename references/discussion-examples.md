## 案例一：人生决策 · 虚构

**问题**：该不该跟创业十年的朋友合伙开公司？
**模式**：串行 2轮 | **角色**：赌徒、寂、爆破手、冰

### 第一轮

🃏 赌徒：跟。梭了。

💀 寂：先弄清楚，他创业十年有没有赚到钱。

💣 爆破手：十年都没赚到钱，说明他根本不是那块料。你跟他合伙就是找死，拿钱往水里扔还得自己憋气。友情是最贵的学费，别交了。

🧊 冰：先统计他近10年创业成功率、净现金流、负债率。成功概率低于65%，合伙是负期望决策。

### 第二轮

💣 爆破手：装什么分析，十年没赚到钱就是答案。你见过鲨鱼跟猎物讲道理？

🃏 赌徒：跟。能创十年还活着，本身就值一押。输了我认。

💀 寂：活着回来的，都清楚怎么接着喘气。生意上的账你自己算。

🧊 冰：韧性量化维度：失败次数（分母）、恢复周期（时间变量）、归因模式（内归因+1分）、债务清偿率（>80%为阈值）、低谷期收入证明。任一维度缺失，合伙风险系数上升。**数据饱和，终止讨论。**

### 石叔总结

**讨论进程**：从直觉到数据。数据出现时讨论正好结束。

**关键冲突对**：爆破手 vs 冰——方法论之争；赌徒 vs 所有人——赌徒不要依据只要行动。

**最终判断**：不跟。不是朋友不值得，是他十年没跑通一个模型，你进去就是替他填坑。可以换种方式帮——借钱、介绍资源、帮他找买家，但别合伙。

## 案例二：技术选型 · 虚构

**问题**：新项目后端选 Node.js 还是 Go？
**模式**：串行 3轮 | **角色**：CTO、VP Engineering、运维负责人、CFO

### 第一轮

👨‍💻 CTO：Go。并发模型干净，部署简单，性能足够。Node 的回调地狱我受够了。

📊 VP Engineering：Node。团队八个人，六个写 JS。你换 Go，招聘周期三个月，培训周期六个月，项目等得起？

🛡️ 运维负责人：Go。单个二进制文件，没有依赖地狱，CI/CD 省心。Node 的 node_modules 每次都让我做噩梦。

💰 CFO：Node。云服务按量计费，Node 内存占用低，Go 的 goroutine 调度反而会吃更多 CPU。——等等，我是不是搞反了？不管，Node 便宜。

### 第二轮

👨‍💻 CTO → VP：你刚才说"团队八个人"，但招聘市场 Go 工程师薪资比 Node 高 20%，你算过吗？

📊 VP → CTO：你刚才说"回调地狱"，但我们有 TypeScript + async/await，这不是五年前了。你停留在哪个版本？

🛡️ → CFO：你刚才说"Go 吃更多 CPU"，但 Go 的编译优化比 V8 好太多，长期跑下来 Go 更省。

💰 → 运维：你别跟我扯技术，我只看账单。Node Docker 镜像 50MB，Go 10MB，但 CPU 时间是钱。

### 石叔阶段性小结

- **话题演化**：从"哪个技术好"→"哪个对业务更划算"
- **核心分歧**：CTO 要先进性，VP 要平滑过渡，运维要部署简单，CFO 要成本可控
- **新变量**：CFO 提到"招聘薪资差 20%"
- **下一轮重点**：CTO 和 VP 互怼"团队能力"

### 第三轮

👨‍💻 CTO：好吧，团队是现实。但能不能用 Go 写核心服务，Node 写业务层？混合架构。

📊 VP：混合架构意味着两套招聘体系、两套 oncall、两套 code review。你确定？

🛡️：混合架构我支持，前提是监控统一。Prometheus 能同时抓 Go 和 Node 的指标。

💰：混合架构云成本比纯 Node 高 15%，比纯 Go 低 10%。可接受。

### 石叔总结

**讨论进程**：从"二选一"→"混合架构"，中间经历技术 vs 业务冲突。

**关键变量**：团队能力、招聘市场、运维复杂度、云成本。

**关键冲突对**：CTO vs VP——技术理想主义 vs 业务现实。

**最终判断**：混合架构。Go 写高并发核心（支付、消息队列），Node 写业务逻辑层。招一个 Go 资深工程师负责底层，业务层不动。过渡期三个月。

## 案例三：家庭关系 · 虚构

**问题**：父母想搬来一起住，该答应吗？
**模式**：串行 2轮 | **角色**：外婆、都市青年、心理咨询师、邻居张大妈

### 第一轮

👵 外婆：答应吧，一家人住一起热热闹闹的。我们老了，也帮你们带带孩子。

👨‍💼 都市青年：不知道……答应了没自己空间，不答应又觉得不孝顺。我同事她爸妈搬来后，她每天回家像回公司。

👩‍⚕️ 心理咨询师：先别急。你害怕的是"失去空间"，还是"不知道怎么拒绝"？这两个不一样。

👮 邻居张大妈：我见过太多住了又搬走的。不是感情不好，是生活习惯太不一样。你妈几点起床？你几点睡觉？这些小事住进去前都不是事，住进去全是事。

### 第二轮

👵 → 都市青年：你刚才说"不孝顺"，但孝顺不是牺牲自己。你过得不好，我们住进来也过得不好。

👨‍💼 → 外婆：你说得对，但我怕我妈说"你就是不想跟我们住"。

👩‍⚕️ → 都市青年：你刚才说"怕我妈说"——你不是在做"要不要一起住"的决定，你是在做"怎么拒绝父母而不被骂"的决定。这两个不一样。

👮：先试住一个月。你妈来"玩"一个月，别正式搬来。一个月后还想让她搬来就搬；不想，也有理由——"妈你住不惯"。

### 石叔总结

**讨论进程**：从"该不该"→"怎么试"，找到中间方案。

**关键变量**：个人空间、父母情绪、试住可行性。

**关键冲突对**：都市青年（焦虑）vs 外婆（传统智慧）——两代人对"孝顺"的理解不一样。

**最终判断**：先试住。让父母来"玩"一个月，不提"搬来住"。舒服再谈正式搬；不舒服也有数据支持，不是纯粹拒绝。

## 案例四：商业决策 · 虚构

**问题**：公司该不该接这个高风险高回报的项目？
**模式**：串行 2轮 | **角色**：王经理、张总、李阿姨、赵猎头

### 第一轮

🎯 王经理：接。风险高回报更高。不搞明年就死了，搞了还有一线生机。

💰 张总：不接。失败了公司破产就不能接。我创过业，赔过的都知道疼。

🏠 李阿姨：接一半。先接小规模试试水，成了再扩大，败了也亏得起。

🕵️ 赵猎头：先看甲方靠不靠谱。之前有没有跑路记录？别项目接了钱收不回来。

### 第二轮

💰 → 王经理：你刚才说"不搞明年就死了"，但死了和慢死有什么区别？慢死还能撑两年。

🎯 → 张总：两年后还有竞争力吗？市场不等人，慢死就是等死。

🏠：别吵了。王经理说得对不冒险没机会，张总说得也对冒险可能完蛋。折中——先接小的。

🕵️：我查了，甲方去年换过三任CEO，股价跌40%。你们还要接吗？

### 石叔总结

**讨论进程**：从"该不该接"→"甲方靠不靠谱"，发现新变量。

**关键变量**：公司存活概率、甲方信用、风险可控性。

**关键冲突对**：王经理（激进）vs 张总（保守）——风险偏好对立。

**最终判断**：不接。不是项目不好，是甲方风险太高。换三任CEO+股价跌40%=内部不稳定。别拿公司命运赌。

## 案例A：单向收敛 · 实测

**问题**：二胎要不要生？
**模式**：结对辩论 3轮 | **配对**：赌徒↔冰 | 老吴↔李阿姨
**日期**：2026-06-08

### 第一轮 [立]

🎰 赌徒：生。两条命赌两条路，赢面翻倍。

🧊 冰：先算账。二胎家庭支出增幅40-60%，母亲职业中断概率增25%，家庭抗风险缓冲期延长3-5年。

💀 老吴：别生。我当年一个娃都快养不起了，二胎？你有多少钱往里填？

👵 李阿姨：生呀！谁家小陈就一个孩子，现在多孤单嘛，两个孩子互相有个伴多好呀！

**共识 25%**（2:2 立场明确）

### 第二轮 [怼]

🎰 → 冰：[怼] "支出增幅40-60%"——你只算成本不算收益，两个孩子的未来收入预期你算了吗？

🧊 → 赌徒：[怼] "未来收入预期"——长子收入已被证实需补贴次子教育支出至22岁，净贡献延迟15年，IRR为负。

💀 → 李阿姨：[怼] "两个孩子互相有个伴"——我当年也这么想，结果两个娃抢资源，老大怨我到现在。

👵 → 老吴：[怼] "一个娃都快养不起"——那是你自己的情况嘛！谁家小陈两口子工资加一起也不少呀，养两个没问题啦！

**共识 40%**

### 第三轮 [收敛]

🎰 赌徒：[怼] 冰你算了15年IRR，但亲情你算不出来——

🧊 冰：[让] 接受"亲情无法量化"的前提。但追加条件：家庭月收入需覆盖二胎增支后仍有20%余量，否则亲情压不过账单。

💀 老吴：[怼] 李阿姨你总说"谁家小陈"，小陈家几套房你知道吗？

👵 李阿姨：[让] 老吴说得也有道理呀……有余量再生也不迟嘛，别硬撑。

**共识 65%**（25→40→65% 单向收敛）

### 石叔总结

**[让]触发逻辑**：冰是在赌徒承认"亲情算不出来"后才让的——不是被说服，是对方承认了方法论边界。李阿姨是在老吴追问"小陈家几套房"后让的——故事被数据质疑，故事就站不住了。

**关键冲突对**：赌徒（赌未来）vs 冰（算成本）——赌徒没有数据，冰不让步直到赌徒承认"算不出来"。

**最终判断**：现在别生，还没资格生。月收入需覆盖二胎增支后仍有20%余量，有余量了再讨论。

## 案例B：对峙不收敛 · 实测

**问题**：父母出首付给你买房还贷30年 vs 租房不背债？
**模式**：结对辩论 3轮 | **配对**：赌徒↔冰 | 老吴↔李阿姨
**日期**：2026-06-08

### 第一轮 [立]

🎰 赌徒：首付别人的钱，杠杆30年拉满。

🧊 冰：锁定360期现金流，流动性折价40-60%。

💀 老吴：我当年还了15年还欠38万，失业3个月差点断供，租房不好吗？

👵 李阿姨：谁家小陈搬家五次，孩子都没着落，租房哪有家呀！

**共识 25%**

### 第二轮 [怼]

🎰 → 冰：[怼] "租金收益率1.5%"——1.5%的账算给谁看？房子30年涨了5倍你跟谁算流动性？

🧊 → 赌徒：[怼] 父母出资比例每增10%，子女话语权下降15-20%。30年总利息1.27倍，首付款投指数30年后是还贷净资产1.4-1.8倍。

💀 → 李阿姨：[怼] "有自己房子心才踏实"——我当年首付60万砸进去，卖了还欠40万，踏实个啥？

👵 → 老吴：[怼] "还了15年还欠38万"——那是你那时候买的早嘛！现在公积金利息低多了，租房那叫家吗，房东说赶人就赶人！

**共识 20%**（比第1轮还低）

### 第三轮 [收敛·失败]

🎰 赌徒：[怼] 冰说"1.4-1.8倍"——1.8倍是算出来的，房子涨5倍是赌出来的，赌赢一次顶你算十年。

🧊 冰：[怼] 公积金3.1%利率下200万贷款30年利息仍达107.9万。现金流断裂的尾部概率，不因利率下行而消除。

💀 老吴：[怼] 李阿姨说"公积金利息低多了"，我当年3.2%照样倒欠38万，利息低不代表不断供，断供一次首付全沉。

👵 李阿姨：[怼] "首付60万还欠40万"那是啥年代的事了嘛！现在3.1利率，谁家小陈早买了现在房子涨了娃也安顿好了！

**共识 15%**（25→20→15%，零[让]，全员[怼]）

### 石叔总结

**讨论饱和，无法收敛。**

**两条平行裂缝**：
1. 赌的是未来还是算的是未来？赌徒押"涨5倍"，冰押"指数1.4-1.8倍"，认知框架互斥。
2. 历史经验能不能迁移？老吴"3.2%照样断供"vs李阿姨"那是以前"，案例不可比。

**沉默共识**（唯一暗线）：四人默认"收入稳定是买房前提"——只是对该不该买结论相反。

**最终判断**：讨论不出答案。先回答四个变量：月供占比≤40%？备用金≥6个月？父母养老钱够吗？你在哪个城市？条件满足则买不买都不至于死，不满足则先别动。

**对峙型出口规则**：共识连续2轮≤20%，石叔宣布"讨论饱和无法收敛"，输出变量框架而非结论。

## 案例C：快收敛 · 实测

**问题**：辞职加入朋友创业团队？
**模式**：结对辩论 2轮 | **配对**：赌徒↔冰 | 老吴↔李阿姨
**日期**：2026-06-08

### 第一轮 [立]

🎰 赌徒：辞。朋友创业是入场券，犹豫的人连上桌资格都没有。

🧊 冰：创业团队1-3年存活率9.7%，辞职加入等于用确定收入换9.7%概率。需要MVP验证数据。

💀 老吴：别辞。我当年就是被朋友拉去创业，80万打水漂，朋友现在都不联系了。

👵 李阿姨：谁家小张也是跟朋友创业呀，现在天天加班到半夜，老婆都要离婚啦！

**共识 25%**（3:1保守）

### 第二轮 [怼]

🎰 → 冰：[怼] "9.7%存活率"——那9.7%活下来的人，你觉得他们后悔加入了吗？

🧊 → 赌徒：[怼] "活下来的人不后悔"是幸存者偏差。未存活者后悔比例>85%。需验证：朋友团队是否有MVP、是否有付费用户、你能否承担18个月零收入的尾部风险。

💀 → 李阿姨：[怼] "小张老婆要离婚"不是创业的错——是我当年太冲动，没看清楚朋友的项目就去了，80万就这么没了。

👵 → 老吴：[怼] 你说"没看清楚就去了"——对呀！所以先别辞，先周末帮朋友干，看清楚再说嘛！

**共识 60%**（25→60% 快收敛）

### 石叔总结

**讨论进程**：核心分歧从"该不该辞"变成"有没有资格辞"——缺数据不是缺勇气。

**关键冲突对**：赌徒（入场券论）vs 冰（幸存者偏差）——赌徒逻辑被数据一压就塌。

**最终判断**：先别辞，没资格去。周末帮朋友干三个月获取数据：团队执行力如何？产品有没有人付钱？你能不能扛住？三个月后带数据再来讨论。

## 实测案例对比

### 质量自检

1. **角色可区分**：遮掉名字能猜出是谁
2. **冲突真实**：不是"A好vs B好"，是同一维度看到不同东西

5. **讨论有演化**：每轮话题在推进，不是重复

### 晚插话衰减效果分析

- **插话引用率**：4/4角色核心引用（100%，反比第1轮后插话的75%更高）
- **[让]触发率**：0个（对比第1轮后插话的2个）——角色用插话强化已有立场而非修正
- **共识提升**：0→40%（对比第1轮后插话的30→55%）

- **对比案例D**：第1轮后插话→2个[让]→55%共识；第2轮后插话→0个[让]→40%共识
- **建议**：石叔应在晚轮次插话的spawn prompt中强调“根据真人信息重新审视你的立场，如需修正用[让]标签”
