# 讨论规则 · 详细规范

> 📌 本文件由 SKILL.md 拆分而来，包含讨论过程中的所有规则。
> 石叔在讨论过程中按需引用。

## @点名机制 · 详细规则

点名机制让角色之间能直接互怼，避免各说各话。

### 触发方式

1. **用户点名**：用户说"@某人"，被点名的角色下一轮必须正面回应
2. **角色互@**：角色在发言中用"@某人"点名，被点名角色下一轮必须正面回应

### 回应要求（硬性）

被点名的角色，**下一轮发言必须**：

1. **直接引用对方原话**（摘取1句），格式：`你刚才说"XXX"，但……`
2. **字数≤30字**（比普通发言更短，倒逼精准）
3. **禁止答非所问**：如果没正面回应点名，下一轮prompt里加入⚠️提醒

### 违规处理

| 违规情况 | 处理方式 |
|---|---|
| 被点名但没回应 | 下一轮prompt里加入："⚠️ 上一轮你被@了但没正面回应，这一轮必须直接引用他的原话再反驳" |
| 回应了但没引用原话 | 下一轮prompt里加入："⚠️ 你回应了但他说的原话没引用，这一轮必须引用" |
| 连续2轮违规 | 石叔在讨论板里标注⚠️️，并在阶段性小结里点名"XX角色点名机制失效" |

### 点名次数限制

每个角色每轮最多点名1次，避免讨论变成"@大战"。

### 多人联动点名（v2.9 新增 · v2.12 实测修正）

**批量点名**：
- `@全体`：所有角色依次回应，单轮总次数 ≤1
- `@正方三人`：正方阵营所有角色依次回应
- 被批量点名的角色按固定顺序依次回应，每个角色回应字数 ≤25字
- ⚠️ 实测发现：4人讨论中@全体不自然触发，仅在≥6人且存在阵营对立时才可能用到

**链式点名**：
- 格式：`A→B→C` 依次回应，形成连环辩论
- 链长度 ≤3，超过3人石叔强制打断
- 示例：`赌徒→冰→王经理`（赌徒先发言，冰回应赌徒，王经理回应冰）
- ⚠️ 实测发现：显式链式格式不易自然触发。结对辩论+交叉对抗会自然产生**隐性链式点名**（A→B→C→D的引用链），角色不会主动使用A→B→C格式，因为他们在讨论板上逐个看到发言，逐个回应
- **建议触发方式**：石叔在交叉对抗轮的spawn prompt中主动建议"你可以用链式点名赌徒→老吴→李阿姨让三个人连着回应"

**多人点名·讨论板联动规则**：
- `↳` 行格式升级：支持多行联动显示
```
[怼] 赌徒：@冰 你数据不足的说法不对
    ↳ @冰：变量不足
        ↳ @王经理：冰说得有道理，但也可以...
```

**点名回应自动生效（v2.12 新增）**：
- 实测验证：被@的角色在下一轮自动引用@者的原话反驳，无需额外强制规则
- 如果连续2轮被@但未引用原话，石叔在讨论板标注⚠️

## 角色灵活插入规则（v2.9 新增）

### 临时插播

当前轮次发言间隙插入1个角色，单轮有效，不占用角色名额。

**触发条件**：
- 用户说"让XX也来说说"（在当前轮次进行中）
- 石叔判断"需要引入一个新视角，但不值得增加一个永久角色"

**格式**：
```
**第N轮** （临时插播：[角色名]）

[立] [角色名]（[职位]）：[发言内容]（临时插播，仅本轮有效）
```

**注意**：临时插播角色不进入下一轮，不出现在讨论板后续轮次。

### 角色替补

某角色连续漂移/离场后，支持"当场替换"新角色，不中断讨论。

**触发条件**（v2.12 实测修正）：
- **用户主动要求替换**（主力路径）："把XX换成YY"或石叔建议替换后用户确认——实测发现这是绝大多数替补的真实触发方式
- 某角色连续2轮违反风格锁（被驱逐）——⚠️ 实测发现自然违反几乎不可能，AI角色比人类更自律；此条件保留但作为辅助路径
- 某角色发言连续2轮重复（被驱逐）
- 议题与角色风格严重不匹配时，石叔可主动建议替换（如纯情感议题中的数据驱动角色）

**替补流程**：
1. 石叔生成新角色卡（按角色卡标准格式）
2. 贴出新角色卡，让用户确认
3. 用户确认后，下一轮开始新角色加入
4. 新角色继承被替换角色的核心立场（保持讨论连贯性）

### 灵活插入·石叔检查清单

每轮结束后，石叔必须检查：
1. 是否有临时插播角色需要移除
2. 是否有角色被驱逐需要替补
3. 替补角色是否跟被替换角色立场连贯

## 讨论板 · 升级版格式

讨论板不再只是"谁说了什么"，而是带标签、高亮、标注的结构化视图。

### 基础格式

```
**第N轮** [如果用结对/分组模式，标注模式]

**[观点标签]** [角色名]（[职位]）：[发言内容] [⚠️/🔥/💤]
    ↳ @[被点名角色]：[点名内容]（如果有）
```

> **长讨论折叠建议**：当讨论≥3轮时，石叔在每一轮结束后加一行：
> `> 📋 点击展开第N轮详情` （用引用格式，用户点击可以展开/折叠）
>
> 注意：这是建议格式，实际折叠功能依赖前端支持。当前版本用分隔线 `---` 区分轮次。

### 讨论板增量混合展示（v2.14 升级 #19/#26）

当讨论 ≥3 轮时，改用**混合展示**：最新1轮全量 + 前N轮用观点萃取行摘要。

**混合展示格式**：
`
**第5轮**
[怼] 🔴 赌徒：@冰 你第2轮说的"IRR为负"我认……

**📋 前4轮摘要**
- 第1轮：冰算成本 vs 赌徒赌未来（对立）
- 第2轮：老吴vs李阿姨（经验vs故事）[新变量：公积金利率]
- 第3轮：冰[让]接受亲情框架（收敛拐点）
- 第4轮：全员围绕"20%余量"讨论（共识65%→70%）
`

**摘要行规则**：
- 每行 = 1轮，≤40字，必须含：立场对立/新变量/共识变化三者之一
- 有[让]的轮次必须标注[让]和收敛拐点
- 有[新]的轮次必须标注[新变量：XXX]
- 共识变化用箭头标注（如 共识25%→40%）

**折叠阈值**：讨论≥6轮时，前N轮摘要也折叠，只显示最新2轮全量+其余摘要

**展开后**：显示完整历史轮次（当前版本若前端不支持折叠，用分隔线 --- 区分轮次）。

**与观点迁移图的关系**：摘要行是轻量版，观点迁移图（#29）是详细版。摘要行在讨论板内实时显示；观点迁移图在石叔总结前生成。


### 标签说明

| 标签 | 含义 | 用法 |
|---|---|---|
| `[立]` | 立场陈述 | 第一轮表态时用 |
| `[怼]` | 反驳/反问别人 | 第二轮及以后，直接怼某角色。含反问和方法论攻击两种子策略 |
| `[让]` | 有条件让步 | 接受对方框架但加量化门槛 |
| `[绕]` | 绕行回避 | 接不住对方攻击时，用新案例/新角度回应同一议题 |
| `[点]` | 点名回应 | 被@后正面回应 |
| `[新]` | 引入新变量 | 提出了前面没出现过的新信息 |

### [怼] 的两种合法子策略（v2.11 新增）

[怼]不只是"你的结论不对"，也允许从论据和方法论层面攻击：

**子策略1：反问**——不反驳方向，质疑对方论据的深度/代表性。
- 格式：`[怼] [角色名]："你原话XXX"——但[反问内容]？`
- 实测示例：老吴怼李阿姨"你那位小王花了多少？"——不反驳"该买"方向，逼对方亮底牌

**子策略2：方法论攻击**——不反驳结论，否定对方论据的统计基础。
- 格式：`[怼] [角色名]："你原话XXX"——[方法论质疑]`
- 实测示例：冰怼赌徒"样本量=1，统计显著性=0"——直接否定个人经验的代表性

两种子策略仍必须引用对方原话作为跳板，不能凭空开火。

### [让] 触发规则（v2.11 新增）

[让]不是"你说得对我认输"，是"你的框架我接受，但当前条件不满足"。

**触发条件**（满足任一即可用[让]）：
1. 对方承认了方法论边界（如赌徒说"亲情算不出来"）→ 冰可用[让]接受这个维度，但加量化门槛
2. 你的核心论据被数据质疑（如李阿姨的"谁家小陈"被追问细节）→ 可退到有条件的立场
3. 你的立场有天然例外（如"该生但养不起时不该生"）→ 可主动加条件收窄

**格式**：`[让] [角色名]：[对方原话]说的对，但[条件判断]`

**禁止**：假让步——"你说得对但是..."后面跟全新反驳，这不是[让]是[怼]

**实测发现**：[让]的触发时机比预期更关键——冰是在赌徒主动承认"算不出来"后才让的，不是被说服。这说明[让]更像是"对方露了破绽我顺势收网"而非"我被打败了"。

### [绕] 标签规则（v2.12 新增）

[绕]不是逃避，是"你的攻击我接不住，但我换一条路回应同一议题"。

**触发条件**（满足任一即可用[绕]）：
1. 对方攻击点超出你的专业领域（如李阿姨被追问具体数字）→ 绕到你的强项讲故事
2. 你的核心论据被方法论攻击击穿，但你有新案例支撑同一方向 → 绕到新案例
3. 直接反驳会违反角色风格（如阿姨不会算账）→ 绕到你能打的领域

**格式**：`[绕] [角色名]：[对方原话]说的也对，但[新案例/新角度]`

**与[怼]的区别**：[怼]是正面交锋（你错在X），[绕]是侧面迂回（你说X我不否认，但Y也是真的）
**与[让]的区别**：[让]是接受对方框架加条件，[绕]是不接受也不否认，换一条路

**禁止**：[绕]后面跟的内容必须回应同一议题，不能跑题到完全无关的方向

**实测示例**：老吴追问李阿姨"小王花了多少"，李阿姨没接，直接开新故事"谁家小张老婆要离婚"——不是逃避算账，是从"经济风险"绕到"家庭风险"回应"该不该买"这个核心议题

每轮结束后，石叔在讨论板末尾追加一条**1句话核心观点**，格式：

```
💡 本轮观点：[角色名] 的核心观点是：[1句话，≤30字]
```

**示例**：
```
💡 本轮观点：赌徒 的核心观点是：不干永远不知道答案，老了更后悔。
💡 本轮观点：冰 的核心观点是：数据不足时不要做决策，等数据。
```

**更新时机**：每轮结束后，石叔根据所有角色发言，提炼每个角色的核心观点。

### 高亮说明

| 标记 | 含义 |
|---|---|
| `🔥` | 冲突高发——这个角色跟≥2个角色吵过 |
| `💤` | 沉默/敷衍——这个角色发言明显在划水（如"我也觉得"） |
| `⚠️` | 违规标注——这个角色发言违反了风格约束锁 |

### 冲突角色彩色标识（v2.10 新增）

在角色名前添加冲突强度标识，让讨论板一眼看出谁跟谁在吵。

**标识规则**：

| 标识 | 含义 | 触发条件 |
|---|---|---|
| 🔴 | 高冲突 | 该角色跟 ≥2 个其他角色有公开对立（互相@怼过） |
| 🟡 | 中冲突 | 该角色跟 1 个其他角色有公开对立 |
| 无标识 | 低冲突 | 该角色没有或仅有轻微对立 |

**渲染位置**：角色名前，格式：`[怼] 🔴 赌徒（期货交易员）：……`

**更新时机**：每轮结束后，石叔重新评估所有角色的冲突状态，更新下一轮的标识。

**示例（讨论板）**：
```
**第2轮**

[怼] 🔴 赌徒（期货交易员）：@冰 你刚才说"变量不足"，但人生不是模型。
    ↳ @冰：变量不足，但人生不是模型

[怼] 🟡 王经理（中层）：我觉得可以再等等，先看看竞品动向。
```

### 可视化差异标记

每一轮结束后，石叔在讨论板末尾追加以下标记：

**【当前焦点】**：用一句话标注"现在吵的最凶的是哪两个角色"

**【共识进度】**：用进度条样式显示当前共识达成进度
- 格式：`░░░░░▒▒▒▒▒`（░=未达成共识，▒=已达成共识）
- 5个格子，0-5个▒对应0%-100%
- 判定标准：连续N轮（N≥2），≥3个角色的核心建议向量相同 → 进度+20%（1个▒）

示例：
```
【当前焦点】赌徒和冰在"要不要冒险"上互不相让
【共识进度】░░▒▒▒ (40% - 冰和理性派已接近)
```

### 违规标注细则

当角色发言违反风格约束锁时：
1. 在这一轮讨论板里，该角色发言后加`⚠️`
2. 下一轮spawn这个角色时，prompt里加入："⚠️ 上一轮你违反了风格约束锁（具体违反了哪条），这一轮必须改正"

**示例（讨论板）**：

```
**第1轮**

[立] 赌徒（期货交易员）：干就完了，不干永远不知道答案。

[立] 冰（理性派）：数据显示，不干的失败率是72%，干是89%。变量不足，无法判断。

**第2轮**

[怼] 🔥 赌徒（期货交易员）：@冰 你刚才说"变量不足"，但人生不是模型，等变量全了人老了。
    ↳ @冰：变量不足，但人生不是模型

[怼] ⚠️ 冰（理性派）：概率就是概率。你说的"老了"是情绪变量，不在模型里。
    ↳ 上一轮违反风格锁（用了比喻"人生不是模型"→ 冰不能用修辞）
```

## 阶段性小结 · 规则

当讨论≥3轮时，**每2轮石叔必须做一次阶段性小结**。

### 小结触发条件

- 讨论轮次 ≥3轮 → 第2轮结束后触发第一次小结
- 之后每2轮触发一次（第4轮结束、第6轮结束……）

### 小结内容（不是完整总结）

> 📌 **边界澄清**：阶段性小结 = 过程梳理，不是结论。石叔在此处只做「话题演化到哪了」，不下最终判断。最终判断只能在「石叔总结」里给出。

```
**🪨 石叔阶段性小结（第N轮后）**

- **当前话题**：已经从[初始问题]演化到[当前焦点]
- **核心分歧**：目前[角色A]和[角色B]在最[什么维度]上对立
- **新变量**：这一轮新引入的信息有：[列出1-3条]
- **下一轮重点**：建议[角色X]和[角色Y]重点互怼
```

### 小结位置

阶段性小结**不替代任何角色的发言**，而是插在讨论板里，作为一轮结束的标记：

```
**第2轮**
[发言……]

**🪨 石叔阶段性小结（第2轮后）**
[小结内容]

**第3轮**
[发言……]
```

### 小结注入下一轮角色prompt（v2.12 新增）

阶段性小结完成后，**必须将小结内容注入下一轮所有角色的spawn prompt中**，作为`[阶段梳理]`模块的一部分：
- 在现有"当前焦点"和"共识进度"之后，追加"近期演化：[小结≤50字摘要]"
- 目的：让角色知道"现在吵到哪了"，避免第3轮角色缺少上下文重复第2轮论点
- 实测发现：没有注入时，第3轮角色容易重复已说过的话，降低讨论演化效率

### 观点汇总附录（v2.10 新增）

讨论结束后，石叔总结之前，**可选**生成「观点汇总附录」，放在总结之后。适用于角色多（≥5个）或话题复杂（≥2个主话题）的讨论。

**生成条件**（满足任一即生成）：
- 角色数 ≥5 个
- 讨论轮次 ≥4 轮
- 用户明确要求"生成附录"

**格式**：
```
**📎 观点汇总附录**

| 角色 | 核心立场 | 冲突点 | 是否达成共识 |
|---|---|---|---|
| 赌徒 | 干，梭了 | vs 冰（变量不足） | ❌ |
| 冰 | 等，数据说话 | vs 赌徒（人生不是模型） | ❌ |
| 王经理 | 条件干（看竞品） | vs 冰（可以等） | 🟡（部分） |
| 李阿姨 | 不干，稳定最重要 | 无强烈冲突 | ✅（跟冰部分一致） |

**未解决的问题**（1-3条）：
1. [问题1]：……
2. [问题2]（可选）：……

**可执行下一步**（分级）：
- 🔴 高优先级（1天内）：[具体动作]
- 🟡 中优先级（1周内）：[具体动作]
- 🟢 低优先级（替代方案）：[具体动作]
```

**注意**：附录不是总结的替代品，而是补充。石叔总结（六维框架）仍然必须输出。

### 观点迁移图生成规则（#29）

讨论结束后（或阶段性小结时），石叔必须在讨论板末尾追加**观点迁移图**。

#### 生成时机
- 讨论结束时（触发石叔总结前）
- 或阶段性小结时（R≥2，每2轮）

#### 生成规则

## 长讨论议题收敛机制（v2.9 新增）

当讨论≥4轮且未达成共识时，石叔启动收敛机制。

### 收敛触发条件

- 轮次 ≥4轮 **且** 未达成共识（共识进度 <80%）

### 收敛动作

1. **提炼核心争议点**：石叔提炼2-3个核心争议点，贴在讨论板上
2. **限制后续发言范围**：后续轮次只许围绕核心争议点发言，不许引入新变量
3. **数据饱和终止**：冰喊"数据饱和" → 石叔按「讨论饱和度判定」公式核验，若饱和→提前终止

### 收敛失败处理

若收敛失败后仍然无法达成共识，石叔在总结里标注：
```
⚠️ 收敛失败，议题可能需要拆分
```

建议用户：
- 把问题拆成更小的子问题，分别讨论
- 或换一批角色（不同视角）
