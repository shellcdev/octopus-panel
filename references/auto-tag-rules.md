# auto-tag-rules.md — 自动标签规则库

> 📌 版本：v1.0 | 更新：2026-06-10 | 维护者：growth_api.update_auto_tags()
>
> 本文档定义所有自动标签的触发条件、置信度计算方法和数据来源。
> 标签置信度 < 60% 时不展示（保留在数据中但不渲染）。

## 详细规则

### DU_WANG · 怼王候选

- **触发条件**：最近 N 场（N≥3）中，冲突密度评分 ≥80 分的场次 ≥3 场
- **置信度公式**：`min(100, 高分场次 / 总场次 × 100)`
- **数据来源**：`stance_history[].score`（由评分卡计算的冲突密度维度得分）
- **示例**：赌徒跑了 5 场，其中 4 场冲突密度 ≥80 → 置信度 = min(100, 4/5×100) = 80%
- **移除条件**：连续 2 场冲突密度 < 50 → 置信度 < 60 → 自动移除

### RANG_MASTER · 让步大师

- **触发条件**：累计 [让] 标签 ≥2 个（跨场累计）
- **置信度公式**：`min(100, 累计[让]次数 × 15)`
  - 2 次 [让] → 30%
  - 5 次 [让] → 75%
  - 7 次 [让] → 100%（封顶）
- **数据来源**：讨论板标签统计，`archive_discussion.py` 在归档时统计
- **注意**：该标签需要讨论板标签解析支持，当前由手动归档时标注

### LV_MAO_KNIGHT · 绿帽骑士

- **触发条件**：参与过 ≥1 场绿帽轮
- **置信度公式**：`min(100, 50 + 绿帽场次 × 15)`
  - 1 场 → 65%
  - 2 场 → 80%
  - 3+ 场 → 100%
- **数据来源**：`stance_history[].stance` 或 `topic` 含"绿"/"🟢"关键词
- **注意**：当前通过文本关键词检测，未来可在归档时传入显式字段

### STANCE_STABLE · 立场稳定

- **触发条件**：累计场次 ≥3，且历史立场种类 ≤2 种
- **置信度公式**：`max(0, 100 - (立场种类数 - 1) × 35)`
  - 1 种立场 → 100%
  - 2 种立场 → 65%
  - 3 种立场 → 30%（<60% 不展示）
- **数据来源**：`stance_history[].stance` 字符串去重
- **示例**：赌徒 3 场说了"梭了开"、"跳！梭了"、"条件梭" → 3 种 → 置信度 30% → 不展示

### STANCE_SHIFT · 立场漂移

- **触发条件**：单场讨论内立场发生过变化（场内出现 [让] 标签 ≥1 次）
- **置信度公式**：`min(100, 场内变化次数 × 30)`
  - 1 次变化 → 30%（<60% 不展示）
  - 2 次变化 → 60%
  - 3+ 次变化 → 100%
- **数据来源**：讨论板 [让] 标签统计（每场）
- **注意**：需要场内标签解析，当前通过 `check_achievements()` 的 `stance_shifted` 上下文传入

### CONSENSUS_CATALYST · 共识催化剂

- **触发条件**：已解锁 "CHANGED_THE_WIND" 成就（发言后共识拐点 ≥20%）
- **置信度**：固定 85%
- **数据来源**：`achievements[]` 成就列表
- **注意**：派生标签，不独立计算，依赖成就检测

### SILENT_PARTNER · 沉默搭档

- **触发条件**：最近 N 场（N≥3）中，低分场次（评分 <40）≥2 场
- **置信度公式**：`min(100, 低分场次 / 总场次 × 100)`
- **数据来源**：`stance_history[].score`
- **示例**：跑了 4 场，2 场评分 <40 → 置信度 = min(100, 2/4×100) = 50%（<60%，不展示）

### GREEN_IDEA_DRIVER · 绿帽思路推动

- **触发条件**：累计 [绿] 引用次数 ≥2（跨场累计）
- **置信度公式**：`min(100, 累计[绿]引用次数 × 20)`
  - 2 次 → 40%（<60% 不展示）
  - 3 次 → 60%
  - 5+ 次 → 100%
- **数据来源**：归档 [绿] 标签计数
- **注意**：该标签需要讨论板 [绿] 引用解析支持

## 标签维护规则

### 自动更新

`growth_api.update_auto_tags(role_id)` 在以下时机自动触发：
1. 每次讨论归档后（由 `archive_discussion.py` 调用）
2. 显式调用（如用户说"刷新角色标签"）

### 标签生命周期

```
首次触发 → 置信度 ≥60% → 展示（存入 auto_tags 列表）
                  ↓
连续表现不达标 → 置信度 < 60% → 自动移除（不展示，保留数据）
                  ↓
重新达标 → 置信度 ≥60% → 自动恢复展示
```

### 置信度阈值

| 区间 | 行为 |
|------|------|
| ≥80% | 展示，在完整档中高亮 |
| 60-79% | 展示，标准显示 |
| <60% | 不展示（保留在 `growth_record` 中但不渲染） |
