# 角色成长系统 · 量化公式

> 📌 本文件记录角色成长系统（v3.0）中所有计算公式。
> 对应实现：`scripts/growth_api.py`

---

## 1. 经验值公式

每场讨论结束时，根据该角色的单场评分和衰减系数计算 EXP 增长。

```
exp_gained = int(score × decay)

新 exp = 旧 exp + exp_gained
新 level = floor(exp / 200) + 1
```

| 参数 | 说明 | 范围 |
|------|------|------|
| `score` | 单场讨论质量评分卡中该角色的维度得分 | 0–100 |
| `decay` | 衰减系数（见下方） | 0.6–1.0 |
| `exp_gained` | 取整后的单场经验值 | ≥ 0 |

### 等级对照表

| 等级 | 所需 EXP |
|------|---------|
| Lv.1 | 0–199 |
| Lv.2 | 200–399 |
| Lv.3 | 400–599 |
| Lv.4 | 600–799 |
| Lv.5 | 800–999 |
| Lv.N | (N-1)×200 – N×200-1 |

## 2. 衰减系数

随着角色总出场次数增加，单场 EXP 收益递减，模拟"经验边际效用递减"。

```
decay = max(0.6, 1.0 - (total_sessions - 1) × 0.02)
```

| 出场次数 | decay | 说明 |
|---------|-------|------|
| 1 | 1.00 | 首战，全收益 |
| 5 | 0.92 | |
| 10 | 0.82 | |
| 20 | 0.62 | |
| 21+ | 0.60 | 硬底，不再降低 |

## 3. 影响力权重

用于 spawn 注入时排序历史记录，决定哪条立场最值得注入。

```
weight = 0.3（基础分）
       + relevance × 0.35（话题相关度，0.1–1.0）
       + (score / 100) × 0.2（历史评分贡献）
       + recency_bonus（时效加分）
       → 上限 1.0
```

### 话题相关度矩阵

| 当前话题 ↓ / 历史话题 → | career | financial | family | technical | general |
|------------------------|--------|-----------|--------|-----------|---------|
| **career** | 1.0 | 0.7 | 0.3 | 0.3 | 0.5 |
| **financial** | 0.7 | 1.0 | 0.3 | 0.3 | 0.5 |
| **family** | 0.3 | 0.3 | 1.0 | 0.1 | 0.5 |
| **technical** | 0.3 | 0.3 | 0.1 | 1.0 | 0.5 |
| **general** | 0.5 | 0.5 | 0.5 | 0.5 | 0.5 |

### 时效加分

| 历史时间 | 加分 |
|---------|------|
| ≤ 1 天 | +0.15 |
| ≤ 7 天 | +0.08 |
| > 7 天 | 0 |

### 注入规则

- **light 模式**：仅注入权重最高的 1 条
- **deep 模式**：注入权重前 3 条，权重 ≥ 0.7 标记 ⭐
- 第 2 轮起不再注入（已在讨论上下文中）
- 跳过 `stance_history_skip_sessions` 中指定的场次

## 4. 成就系统

7 种自动检测成就，每种仅触发一次。

| 成就 ID | 名称 | 触发条件 |
|---------|------|---------|
| `CHANGED_THE_WIND` | 改变过风向 | 该角色立场被其他 2+ 角色跟进 |
| `THREE_SESSION_VETERAN` | 三场老将 | 累计出场 ≥ 3 |
| `TEN_SESSION_VETERAN` | 十场老将 | 累计出场 ≥ 10 |
| `FIRST_STANCE_SHIFT` | 首次立场变化 | 单场讨论中立场发生改变 |
| `HIGHEST_SCORE` | 生涯最高分 | 单场评分超过历史最高 |
| `LOWEST_SCORE` | 生涯最低分 | 单场评分低于历史最低 |
| `FIRST_CONSENSUS` | 首次默契 | 首次与其他角色同时[让]，达成共识 |

### 里程碑事件

| 事件 | 触发 |
|------|------|
| `5_SESSIONS` | 累计出场 ≥ 5 |
| `10_SESSIONS` | 累计出场 ≥ 10 |
| `20_SESSIONS` | 累计出场 ≥ 20 |
| `50_SESSIONS` | 累计出场 ≥ 50 |
| `FIRST_STANCE_SHIFT` | 首次立场变化 |
| `HIGHEST_SCORE` | 刷新生涯最高分 |
| `LOWEST_SCORE` | 刷新生涯最低分 |

## 5. 自动标签

标签由 `auto-tag-rules.md` 中的置信度公式驱动，非本文件范围。简要对应：

| 标签 | 触发维度 |
|------|---------|
| 怼王候选 | [怼] 密度 + 冲突贡献 |
| 让步大师 | [让] 密度 + 共识贡献 |
| 绿帽骑士 | 绿帽轮 [新] 标签密度 |
| 立场稳定 | 立场变化率低 |
| 立场漂移 | 立场变化率高 |
| 共识催化剂 | 促成共识频率 |
| 沉默搭档 | 出场率低 |
| 绿点驱动者 | 绿帽轮有效建议数 |
