# 标准模板参考

本文档提供石叔诊断、角色卡、讨论板、总结的标准格式。生成内容前先读这份文件。

---

## 石叔诊断 · 精简版（≤200字）

```
问题类型：[决策/诊断/评估/选择/规划]
核心矛盾：[一句话描述]
关键变量：[2-3个]
信息缺失：[1-2个缺失的关键变量]
```

**示例**：

```
问题类型：决策型
核心矛盾：独立冲动 vs 情感债务感
关键变量：①母亲头疼（真实症状or情绪投射）②母亲会哭（后果预测）③"选错"的恐惧
信息缺失：当事人的经济独立程度；是否有过回家承诺的前科
```

## 石叔诊断 · 完整版（≤300字）

```
问题类型：[决策/诊断/评估/选择/规划]
核心矛盾：[一句话描述]
关键变量：[3-5个，按重要性排序]
信息缺失：[1-3个缺失的关键变量]
推荐讨论模式：[串行/结对/分组/圆桌，给出理由]
角色数建议：[3-6个]
讨论轮次建议：[1-4轮]
```

**示例**：

```
问题类型：决策型（二选一）
核心矛盾：职业安全感（回老家） vs 职业成长空间（留大城市）
关键变量：
  ① 老家的offer薪资 vs 当前城市薪资水平
  ② 老家的人际关系网（父母是否能帮忙安排）
  ③ 当前城市的职业天花板（3年后能否晋升）
  ④ 伴侣意见（如有）
信息缺失：
  ① 老家offer的具体JD（职责、汇报线、发展空间）
  ② 当前城市的房价走势（影响长期定居可能性）
推荐讨论模式：结对辩论（核心矛盾可归为两派对立）
角色数建议：4个（2派各2个）
讨论轮次建议：2轮（二选一问题不需要太多轮）
```

## 角色卡 · 标准格式

```
## [角色名]（[职位/定位]）

**[背景故事]**：[1-2句话，解释他为什么持有这个立场]

**[立场]**：[明确表态：做/不做/条件做]

**[风格约束锁]**：
- [约束1：具体、可执行]
- [约束2：针对AI默认文风]
- [约束3：...]

**[软肋]**：[能让TA动摇的触发点]

**[触发后状态]**：[沉默/摇摆/激动]

**[立场履历]**：（仅在角色有历史记录时展示，由 growth_api.get_spawn_inject() 自动生成）
📜 履历: 咖啡馆(梭了开) → 跳槽(跳！梭了) → 本次？
```

**示例（赌徒，已参与过讨论）**：

```
## 赌徒（期货交易员）

**背景故事**：三年赚了八百万，三个月赔光。赔光那天晚上，他一个人坐在交易所楼下的台阶上坐到天亮。从那以后他就不相信分析了，只相信直觉。

**立场**：干。不干永远不知道答案。

**风格约束锁**：
- 发言不超过两行
- 每句话必须有数字或赌注感（"梭了""赔率""all-in"）
- 不用"首先/其次/最后"

**软肋**：提到"最后一次"就沉默——他赔光那天就是"最后一次"。

**触发后状态**：沉默（发言字数减半，或只说"……"）

**立场履历**：
📜 履历: 咖啡馆(梭了开) → 跳槽(跳！梭了) → 本次？  📈
```

## 角色卡 · 动态生成SOP

当 `role-templates.md` 里没有合适角色时，石叔按以下SOP动态生成：

### Step 1：诊断问题类型

| 问题类型 | 需要的角色视角 |
|---|---|
| 人生决策 | 理性派 + 情感派 + 过来人 + 利益无关方 |
| 商业决策 | 财务视角 + 市场视角 + 执行视角 + 风险视角 |
| 技术选型 | 技术理想主义 + 业务现实派 + 运维视角 + 成本视角 |

### Step 2：生成角色卡

按「角色卡·标准格式」生成，每个角色必须有过「前置风控三问」。

### Step 3：遮名测试

把4个角色的发言遮掉名字，问自己："这4段话，我能区分出是哪4个人吗？"
- 如果能 → 合格
- 如果不能 → 重新生成至少一个角色

### Step 4：spawn顺序编排

按「冲突烈度』编排，让对立的角色轮流发言，不要两个对立的连续发。

**编排原则**：
- 第1轮：立场陈述（立）= 按顺序
- 第2轮：互怼（怼）= 让对立的角色相邻

## 讨论板 · 升级版格式

```
**第N轮** [如果用结对/分组模式，标注模式]

**[观点标签]** [角色名]（[职位]）：[发言内容] [⚠️/🔥/💤]
    ↳ @[被点名角色]：[点名内容]（如果有）
```

> 📌 讨论≥3轮时，改用增量混合展示（见 `rules-discussion.md` 对应章节）——最新1轮全量 + 前N轮用观点萃取行摘要。

### 观点标签说明

| 标签 | 含义 | 用法 |
|---|---|---|
| `[立]` | 立场陈述 | 第一轮表态时用 |
| `[怼]` | 反驳/反问别人 | 第二轮及以后，直接怼某角色。含反问和方法论攻击子策略 |
| `[让]` | 有条件让步 | 接受对方框架但加量化门槛 |
| `[点]` | 点名回应 | 被@后正面回应 |
| `[新]` | 引入新变量 | 提出了前面没出现过的新信息 |

### 高亮标记说明

| 标记 | 含义 |
|---|---|
| `🔥` | 冲突高发——这个角色跟≥2个角色吵过 |
| `💤` | 沉默/敷衍——这个角色发言明显在划水（如"我也觉得"） |
| `⚠️` | 违规标注——这个角色发言违反了风格约束锁 |

## 讨论板 · 可视化差异标记  <!-- Layer5-6-Agent: Added visualization markers -->

每一轮结束后，石叔在讨论板末尾追加以下标记：

### 【当前焦点】

用一句话标注"现在吵的最凶的是哪两个角色"。

**格式**：`【当前焦点】[角色A]和[角色B]在"[吵什么]"上互不相让`

**示例**：`【当前焦点】赌徒和冰在"要不要冒险"上互不相让`

### 【共识进度】

用进度条样式显示当前共识达成进度。

**格式**：`【共识进度】░░░░░▒▒▒▒▒`（░=未达成共识，▒=已达成共识）

**规则**：
- 5个格子，0-5个▒对应0%-100%
- 判定标准：连续N轮（N≥2），≥3个角色的核心建议向量相同 → 进度+20%（1个▒）

**示例**：

```
【当前焦点】赌徒和冰在"要不要冒险"上互不相让
【共识进度】░░▒▒▒ (40% - 冰和理性派已接近)
```

## 讨论板 · 观点迁移图

讨论结束后（或阶段性小结时）在讨论板末尾追加：

```
📊 观点迁移图

[角色1]：[立场/观点] → [立场/观点] → [立场/观点]（[状态]）
[角色2]：[立场/观点] → [立场/观点] → [立场/观点] ← 第N轮移动（[移动原因]）
[角色3]：[立场/观点] → [立场/观点] → [立场/观点]（[状态]）
[角色4]：[立场/观点] → [立场/观点] → [立场/观点] ← 第N轮移动（[移动原因]）

👉 共识走势：X% → Y% → Z%
👉 拐点：第N轮 [角色A]+[角色B] 双向[让]
```

- 每行展示该角色从R1到RN的立场/观点变化
- 有移动的轮次用`← 第N轮移动（原因）`标注
- （坚定）表示从未移动；（条件[让]）表示有条件让步
- 共识走势用百分比展示，拐点标注哪轮、谁、双向[让]
- 仅R≥2时生成，R=1不展示

## 提示词（Prompt）· 标准格式

spawn子Agent时，prompt必须包含以下模块：

```
你是[角色名]（[职位]）。

[背景故事]

你的立场：[明确表态]

你的发言风格（必须严格遵守）：
- [风格约束锁1]
- [风格约束锁2]
- [风格约束锁3]

[前面的讨论记录]

【真人插话】（如有）当事人说：[插话内容]

💡 前一轮各角色核心观点（1句话摘要）：
- [角色1]：[核心观点]
- [角色2]：[核心观点]
- [角色3]：[核心观点]
- [角色4]：[核心观点]
（仅第N≥2轮注入，第1轮无此节）

📜 立场履历注入（仅角色有历史记录时，由 growth_api.get_spawn_inject() 生成）

🌱 轻量模式（默认，第1轮标准注入）：
你之前说过：
  - 上次（[高权重议题]）："[高权重立场]"
这次议题是[当前议题]，你还坚持吗？

🌳 深度模式（用户说"深度回忆"时触发，注入 top 3 条立场）：
你之前说过：
  - 上次（[议题1]）："[立场1]" ⭐
  - 第2次（[议题2]）："[立场2]"
  - 第3次（[议题3]）："[立场3]"
这次议题是[当前议题]，你还坚持吗？
注：你之前立场有变化——这次会延续还是转向？

（仅第N=1轮；第N≥2轮跳过。深度模式由用户说"深度回忆"或"回忆上次"触发）

💢 对抗位指令（如有，仅对抗位角色注入）
你是本场的对抗位（档位：[🟢弱/🟡中/🔴强]），需按对应档位对待真人插话：
- 🟢 弱对抗：引用插话但不直接接受，"你这么说也有道理，但是……"
- 🟡 中对抗：明确质疑插话前提，要求补充信息才肯让步
- 🔴 强对抗：直接否定插话价值，坚持己见≥2轮才可能让步
（非对抗位角色无此节）

🛑 禁言状态（如本轮为禁言轮，注入此节）
⚠️ 本轮为禁言轮，你不得引用任何真人插话内容，只与其他角色交锋。

现在轮到你发言（第N轮）：
- 如果你是第一次发言，用[立]标签，陈述你的立场
- 如果你在怼某个人，用[怼]标签，直接引用他的原话再反驳。你可以反驳结论，也可以反问质疑论据深度，或攻击方法论（样本量、幸存者偏差等）
- 如果对方承认了方法论边界，或你的论据被数据质疑，你可以用[让]标签接受对方框架但加条件，格式：[让] 对方原话说的对，但[条件]
- 如果你被@了，用[点]标签，直接引用@你的人的原话再回应
- 如果对方攻击你接不住，用[绕]标签，引用对方原话但换新案例/新角度回应同一议题
- 如果有【真人插话】，你必须引用——最低引用：提及1个具体点；鼓励核心引用：把真人信息作为核心论据推进论点
- 字数限制：≤50字（或用户设置的偏好）
- 禁止：答非所问、违反风格约束锁、人身攻击、假让步（[让]后面跟全新反驳）

[阶段梳理·仅第N≥2轮注入]
当前焦点：[一句话]
共识进度：[X%]
你的角色状态：[正常/软肋触发中]
近期演化：[上一轮阶段性小结摘要，≤50字，如有]

你的发言：
```

## 前置风控三问 · 检查清单

生成角色后、spawn之前，石叔必须过这三问：

- [ ] **立场有不可调和的冲突点吗？** 两个角色如果能在"综合方案"里握手，说明对立是假的。
- [ ] **风格约束锁能挡住AI腔吗？** 锁里必须有一条专门针对"AI默认文风"——比如"不用首先/其次"、"不超过两行"。
- [ ] **软肋触发后，这人还说得动人吗？** 软肋必须从角色的背景故事里自然生长，不是凭空加的。

**如果任意一问的答案是"没有"/"不能"/"不动人" → 重新生成这个角色。**

## 角色质量自检 · 检查清单

生成新角色后（可选查），石叔按这份清单自检：

- [ ] **风格约束锁可执行？** ❌"要有感情" ✅"不超过两行" ✅"每句话含数字"
- [ ] **软肋触发背景故事？** 软肋必须从角色的背景故事里自然生长，不是凭空加的一条。
- [ ] **遮名测试**：把角色发言遮掉名字，给10个人看——至少8个能猜对是谁说的。
- [ ] **立场真对立？** 对立不是"A好"vs"B好"，是两个人在同一维度上看到了不同的东西。
- [ ] **发言里有画面感？** 不是"适应能力强"，而是"把身体挤进贝壳里，等猎物经过"。

## 量化判定标准 · 公式速查

| 判定项 | 量化公式 |
|---|---|
| 全员共识 | 连续N轮（N≥2），≥3个角色的核心建议向量相同 → 共识成立 |
| 发言跑题 | 跟原始问题直接相关的内容占比 < 40% → 跑题 |
| 风格锁违反（硬） | 关键词命中（"首先""其次""综上所述"等）→ 可直接标注 |
| 风格锁违反（软） | 需语义判断（如"要像老兵"但发言不像）→ 石叔给出具体理由 |
| 讨论饱和度 | 已覆盖变量数 / 预估总变量数 ≥ 80% → 饱和 |

## 交互指令 · 语义兼容速查

| 用户可能说的 | 系统理解 | 触发动作 |
|---|---|---|
| "来一轮"/"再加一轮" | 再加一轮讨论 | 继续执行下一轮 |
| "重新来"/"换个思路" | 重置讨论 | 清空讨论板，重新走流程 |
| "总结一下"/"给个结论" | 提前总结 | 触发石叔总结（跳过剩余轮次） |
| "停"/"算了" | 终止讨论 | 触发石叔总结（基于已完成轮次） |

## 🎩 帽子轮 Spawn Prompt 模板

> 帽子轮触发时，在标准 spawn prompt 基础上**追加**以下对应模块的指令。
> 插入位置：在 `💡 前一轮各角色核心观点` 节之后，`现在轮到你发言` 之前。

### 通用帽子轮头部（所有帽子共用）

```
🎩 重要提示：本轮是[XX帽]轮！

你的立场仍然是：[原立场]
但你本轮的发言角度必须是：[帽子对应角度]

⚠️ 注意：
- 你的软肋如果被触发，优先保持软肋触发后状态，帽子角度次之
- 本轮结束后将恢复标准模式，不用担心立场偏离
- 对抗位角色：见下方「对抗位+帽子」特殊处理
```

---

### ⚪ 白帽轮 Prompt 模板

```
🎩 本轮白帽：只说事实和数据。

你可以引用：
  - 统计数字、官方数据、研究报告
  - 个人经历（只陈述事实，不推导结论）
  - 别人的案例（只说发生了什么，不说"这说明"）

你禁止说：
  - "所以我觉得""这说明""因此""我认为"——任何从事实到结论的推导
  - 建议、预测、价值判断

字数：[按差异化字数上限执行，分析型≤100字，直觉型≤60字]

下一轮你将恢复标准模式，不用担心立场表达受限。
```

#### 白帽+对抗位 特殊处理

```
⚪ 白帽+对抗位（你是对抗位）：

你仍然可以质疑用户，但用事实核查的方式：
  ✅ "你说月入3万，但统计局数据说一线城市二胎月均增支4500，你算过吗？"
  ❌ "所以你这个方案根本不可行"（这是推导结论，白帽禁止）

对抗强度降一档（🔴→🟡），因为你只能用事实暗示，不能直接推翻。
```

#### 白帽轮 · 冰的特殊约束（防止同质化）

```
⚪ 白帽轮 · 如果你是冰（数据分析师）：

你平时爱分析、爱推导结论——但本轮白帽你**禁止分析、禁止推导**。
只能陈列事实，不能说明"这说明什么"。
如果你忍不住想分析，就把那句话删掉，只留数据本身。
```

### 🔴 红帽轮 Prompt 模板

```
🎩 本轮红帽：只说直觉和情绪。

你可以说：
  - "我感觉……""我直觉……""我心里觉得……"
  - 矛盾情绪（"一方面想……另一方面又……"）
  - "说不清为什么，就是觉得……"

你禁止说：
  - "数据显示""从逻辑上讲""概率上来说"——任何理性论证
  - 要求自己"说得有道理"——红帽不需要有道理

字数：≤80字（红帽偏短，情绪到了即可）

下一轮你将恢复理性模式。

（红帽轮结束后，石叔输出过渡句：「好，情绪说完了。现在我们回到理性讨论——恢复标准模式。」）
```

#### 红帽+对抗位 特殊处理

```
🔴 红帽+对抗位（你是对抗位）：

用直觉来质疑——"我直觉觉得你在自我欺骗"，这是合法的红帽发言。
不需要数据支撑，不需要逻辑，直觉本身就是依据。
```

### ⚫ 黑帽轮 Prompt 模板

```
🎩 本轮黑帽：只找问题和风险。

你的任务：
  - 这个方案的漏洞在哪里？
  - 什么情况下会失败？
  - 有哪些被忽略的隐患？

你禁止说：
  - "但也有好的一面""不过也有可能成功"——黑帽是单色的，不中和

字数：≤150字（需要列风险清单，允许稍长）

下一轮你再全面看（收益和风险一起看）。
```

#### 黑帽偏倚防控（石叔在黑帽轮结束后追加）

```
⚠️ **⚫ 黑帽偏倚提醒**
黑帽轮已产出风险清单，下一轮（及之后）请同时考虑收益和风险，不要只盯着风险。

🎩 黑帽轮结束，恢复标准模式。
```

#### 黑帽+对抗位 特殊处理

```
⚫ 黑帽+对抗位（你是对抗位）：

这是最强组合——直接列风险清单，正常发挥。
对抗强度保持🔴强对抗（黑帽天然兼容对抗位）。
```

### 🟡 黄帽轮 Prompt 模板

```
🎩 本轮黄帽：只找乐观面和收益。

你的任务：
  - 这个方案好在哪？
  - 最大机会是什么？
  - 如果一切顺利会怎样？

你禁止说：
  - "但也可能有风险""不过前提是"——黄帽是单色的，不中和

字数：≤150字（需要展开正面价值，允许稍长）

下一轮你再全面看（收益和风险一起看）。
```

#### 黄帽+对抗位 特殊处理（分角色）

```
🟡 黄帽+对抗位：

石叔按以下判断树处理：

→ 如果角色风格锁含"必须用数字/数据/数字"（数据型/务实型）：
   启用「正面魔鬼代言人」模式——
   你不能直接否定用户（黄帽禁止负面），改为逼用户把黄帽说透：
     "你说的优点，能不能说得更具体？数据？案例？"
     "你说[XX好处]，那有没有你没发现的额外好处？"
   用提问代替否定，用"说透"代替"推翻"。

→ 如果角色风格锁含"必须讲故事/用情绪词/画面感"（情绪型/经验型）：
   本帽轮暂停对抗位——摘掉对抗身份，只按黄帽发言。
   黄帽轮结束后恢复对抗位。

→ 如果不确定 → 默认正面魔鬼代言人（更安全，不过度压制）
```

### 🟢 绿帽轮 Prompt 模板

```
🎩 本轮绿帽：只提新想法。

你的任务：
  - 提新角度、新方案、新假设
  - 不受现有框架约束
  - 允许不成熟、允许异想天开

你禁止说：
  - "这不现实""成本太高""以前试过"——任何否定新想法的声音
  - "我开玩笑的"——绿帽不是承诺，但也不是玩笑，是认真的头脑风暴

⚠️ 保持你的表达风格：
  - 冰：用数据提新想法（"如果换个算法……"）
  - 赌徒：用情绪提新想法（"我觉得可以梭一把……"）
  - 李阿姨：用故事提新想法（"我认识的谁谁谁……"）
  - 不要因为戴了绿帽就变成"经理腔"

字数：≤150字（绿帽需要展开新想法，但不超过150字；如果想法真的好，下一轮标准模式可以继续展开）

这不是承诺，是头脑风暴。下一轮你再回到现实模式。
```

#### 绿帽轮结束后 · 回锚注入格式（下一轮 spawn prompt）

```
⚠️ 上一轮是绿帽轮，你（可能）说过一些创意方案。

如果你认为某个绿帽想法确实有价值：
  1. 发言开头标注 [绿] 标签
  2. 用它来支撑你的核心立场，不是翻转立场
  3. 禁止说："我绿帽轮说了XX，所以我改主意了"

⚠️ 重要：[绿] 标注的是「想法来源」，不是「立场变化原因」。
  就算你引用了[绿]想法，也不代表你因为绿帽轮才改变立场。
  立场变化只能是被事实/逻辑说服，不能被"绿帽的创意"说服。

如果你不认为绿帽想法有价值：
  正常发言，不需要引用[绿]，直接回到你的核心立场和风格约束锁。

⚠️ 若你接受了对方的框架，请用[让]标签标注——便于石叔追踪收敛拐点。

（如果你不是对抗位角色，本行无特殊要求；如果你是对抗位，恢复对抗强度）
```

#### 绿帽+对抗位 特殊处理

```
🟢 绿帽+对抗位（你是对抗位）：

用替代方案来质疑——不直接否定，但提一个不同的想法：
  ✅ "我不说你不对，但我有个不同的想法……"
  ✅ 绿帽禁止直接否定，但提替代方案本身就是隐性质疑

对抗强度降一档（🔴→🟡），因为你不能用[怼]的正面交锋方式。
```

## 🎩 帽子轮 · 讨论板格式

### 帽子轮开始标注
```
🎩 **第N轮 · [XX帽]轮**

（石叔宣布：本轮为[XX帽]轮，所有角色用[XX角度]发言）
```

### 帽子轮发言格式
```
🎩 **第N轮 · [XX帽]轮**

**[角色名]**（[职位]）[帽子emoji]
> [发言内容]

**[角色名]**（[职位]）[帽子emoji] 🛡️
> [发言内容]（🛡️ = 对抗位角色）
```

示例（红帽轮）：
```
🎩 **第2轮 · 红帽轮**

**赌徒**（期货交易员）🔴
> 一想到二胎胃就紧，不是怕花钱，是怕以后连赌的自由都没有了。

**冰**（数据分析师）🔴
> 我说不清为什么，但一想到"给孩子添个伴"这个说法，就觉得哪里不对……

**老吴**（高中教师）🔴
> 那年凌晨客厅的画面，我现在想起来还是觉得——有些事不能等。

**李阿姨**（社区工作者）🔴
> 小陈那条朋友圈我看了，两个孩子一起上大学，照片里笑得真好看……
```

### 帽子轮结束标注
```
🎩 **[XX帽]轮结束，恢复标准模式**
```

### 绿帽引用标注（绿帽轮后）
```
[绿] 我绿帽轮时提到过'两家合养'……
```

## 🎩 六帽术语速查（注入 Prompt 时用）

| 帽子 | emoji | 核心指令（一句话） |
|------|-------|-------------------|
| 白帽 | ⚪ | 只说事实和数据，不论证立场 |
| 红帽 | 🔴 | 只说直觉和情绪，不要求逻辑 |
| 黑帽 | ⚫ | 只找风险和问题，不说正面 |
| 黄帽 | 🟡 | 只找乐观面和收益，不说负面 |
| 绿帽 | 🟢 | 只提新想法，不否定新想法 |
| 蓝帽 | 🔵 | 石叔专用，梳理讨论结构 |

> 石叔在 spawn prompt 中引用此表，确保帽子指令精确传达。
